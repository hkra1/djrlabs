# Security Policy

We take security seriously and maintain a simple process for reporting issues.

## Reporting a vulnerability
If you discover a security issue, please report it privately to the repository maintainers.

- Do not disclose the issue publicly until it has been assessed and addressed.
- Include reproduction steps and affected versions when possible.
- Prefer private communication through project maintainers or repository contact.

## Current posture
This is a static portfolio hosted on GitHub Pages. It does not expose a backend, database, or secrets in the frontend. The main risks are external dependency compromise and misconfiguration of the domain or contact form integration.
